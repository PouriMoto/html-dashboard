Background images / تصویر پس‌زمینه
===================================
Optional. Put an image here (recommended: dark, soft, 1920x1080, .webp) and set it in data/projects.json:

  "settings": { "backgroundImage": "assets/backgrounds/background.webp" }

The dashboard darkens it automatically so text stays readable. If the file is missing,
the normal dark gradient background is used. You can also set --bg-image in assets/css/theme.css.

Naming: background.webp. Keep it dark and under 300 KB.
