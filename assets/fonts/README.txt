Fonts / فونت‌ها
===============
The dashboard works with system fonts. To use a Persian font (for example Vazirmatn):
  1. Put the .woff2 files here (e.g. Vazirmatn-Regular.woff2 and Vazirmatn-Bold.woff2).
  2. In assets/css/style.css, uncomment the @font-face block at the very top.
  3. If you use another family name, put it first in --font-ui in assets/css/theme.css.
Check the font's license before publishing it. No network request is made if no font is installed.
