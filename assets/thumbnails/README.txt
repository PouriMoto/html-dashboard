Thumbnails / تصویرهای بندانگشتی
================================
Put project cover images here (recommended 16:9, for example 1280x720, .webp or .jpg).

In the dashboard: Edit project -> "مسیر تصویر پوشش", then type, for example:
  assets/thumbnails/inflation.webp
(or set "cover.thumbnail" in data/projects.json).

Rules: the path must be inside assets/, relative (no leading "/" and no ".."), and end with
png, jpg, jpeg, webp, gif, svg or avif. Remote images are not allowed on purpose.
If the file is missing or broken, the card shows the gradient + emoji fallback instead.
