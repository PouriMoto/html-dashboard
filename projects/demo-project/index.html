پروژهٔ نمونه

این یک پروژهٔ HTML مستقل است

هر پوشه‌ای با یک index.html داخل projects/ می‌تواند در داشبورد ثبت شود. شمارندهٔ زیر نشان می‌دهد که پروژه می‌تواند از localStorage خودش استفاده کند.

۰

ثبت این پروژه در data/projects.json:

{
  "id": "demo-project",
  "title": "پروژهٔ نمونه",
  "categoryId": "prototypes",
  "entry": { "localPath": "projects/demo-project/index.html" }
}
