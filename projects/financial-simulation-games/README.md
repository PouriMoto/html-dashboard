پس‌زمینه دو هاله‌ی رادیال کاراملی داره که حس «رویال» می‌ده. رنگ قهوه‌ای تیره برای متن (#3b2a1c) کنتراست بالا با کرم روشن می‌سازه.

چطور آدرس بدهیم؟
حالت ۱ — باز کردن مستقیم با دوبار کلیک (file://)
فقط index.html رو باز کن. آدرس می‌شه:

text
file:///C:/Users/.../financial-city/index.html
لینک‌های نسبی مثل 01-game-a-....html کار می‌کنن. اما localStorage بین فایل‌های file:// مشترک نیست، پس تیک ✅ خودکار نمی‌آد و باید از «کد پروفایل» بازی ۵ استفاده کنی.

حالت ۲ — سرور محلی (توصیه‌شده)
bash
cd financial-city
python -m http.server 8000
آدرس: http://localhost:8000/ — حالا همه‌ی بازی‌ها از یه دامنه باز می‌شن، localStorage مشترکه و تیک ✅ خودکار میاد.

روی گوشی/هاست رایگان: پوشه رو روی Netlify Drop یا GitHub Pages بذار → https://username.github.io/financial-city/

چطور بازی جدید اضافه کنیم؟
فقط یه آیتم به آرایه‌ی window.TRAIL در index.html اضافه کن:

javascript
{
  n: 6,                         // شماره‌ی مسیر
  id: 'game-f',
  emoji: '🎯',
  title: 'هدف‌گذاری هوشمند',
  desc: 'توضیح کوتاه ۱ تا ۲ خطی برای کاربر.',
  tags: ['هدف', 'برنامه'],
  duration: '۱۲ دقیقه',
  file: '06-game-f-hadaf-gozari.html',
  key: 'fc_game_f'              // کلید localStorage برای تیک ✅
}
هیچ تغییر دیگه‌ای لازم نیست. مسیر خودکار بلندتر می‌شه، شماره‌گذاری درست می‌شه، و کارت جدید با انیمیشن ظاهر می‌شه.
